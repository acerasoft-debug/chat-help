VESTRA CJK font (vestra-cjk.ttf)
================================

This file is a SUBSET of WenQuanYi Zen Hei, redistributed under its own
licence. It is here for one reason: an invoice must be able to print the
buyer's own company name and address. A Hong Kong buyer registered on
5 Sep 2026 and the document printed "??????????" instead of the company
name, because the built-in PDF font (Helvetica / WinAnsi) carries only
Western European characters.

What was changed
----------------
Built from face 0 of wqy-zenhei.ttc with fontTools:
  * kept  : Latin, Latin-1/Extended-A, punctuation, currency, Greek, Cyrillic,
            CJK punctuation and fullwidth forms, kana, Hangul (Jamo + syllables),
            CJK Unified Ideographs incl. Extension A, CJK Compatibility Ideographs
  * dropped: embedded bitmaps (BDF), GSUB/GPOS/GDEF, vertical metrics, hinting,
            glyph names
Nothing in the outlines was altered.

At run time inc/pdf_font.php embeds only the glyphs a given document actually
uses, so a typical invoice carries a few KB of this font, not 10 MB.
