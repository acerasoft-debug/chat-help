## Steps
1. Buy domain → publish the VESTRA site (landing live, policies linked in footer).
2. Fill placeholders in the docs above; lawyer review.
3. Submit Business Overview + policies + A/B documents to Tazapay → complete KYB.
4. On approval, integrate the escrow flow (Phase 1).

*If Tazapay declines: same pack works for **Escrow.com** (US-licensed) or Stripe/PayPal.*
